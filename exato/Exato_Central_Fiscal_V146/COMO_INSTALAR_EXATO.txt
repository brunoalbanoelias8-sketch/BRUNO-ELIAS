EXATO CENTRAL FISCAL — COMO INSTALAR E COMEÇAR
Versão: V145

============================================================
1. INSTALAÇÃO EM UM COMPUTADOR NOVO
============================================================

1) Receba o arquivo .ZIP completo do Exato Central Fiscal.
2) Salve o ZIP em uma pasta do computador.
3) Clique com o botão direito no ZIP e escolha "Extrair tudo...".
4) Extraia a pasta inteira para um local de sua preferência.
5) NÃO execute o programa de dentro do ZIP e não remova arquivos da pasta extraída.
6) Abra a pasta da versão e execute INICIAR.bat.

O programa verifica se o computador possui Python 3.12 ou superior.

IMPORTANTE:
- Não execute o arquivo .py diretamente.
- Não apague a pasta assets, pois ela contém logos, identidade visual e Exatinho.
- Mantenha a estrutura completa da versão.

============================================================

1) Baixe o novo ZIP.

============================================================
6. CENTRAL COMPARTILHADA — DOIS OU MAIS COMPUTADORES
============================================================

A V143 pode trabalhar com uma única Central pela rede local.

COMPUTADOR 1 — SERVIDOR CENTRAL
1) Abra o Exato.
2) Na tela de login, clique em CONFIGURAR CENTRAL COMPARTILHADA.
3) Escolha "Este computador é o Servidor Central".
4) Ative o servidor e confirme a configuração.
5) O sistema gera EXATO_CENTRAL_CONEXAO.txt na área de dados do Exato.

COMPUTADORES 2, 3, ... — CLIENTES
1) Instale a mesma versão do Exato normalmente.
2) Na tela de login, clique em CONFIGURAR CENTRAL COMPARTILHADA.
3) Escolha "Conectar a um Servidor Central existente".
4) Use IMPORTAR ARQUIVO DE CONEXÃO e selecione EXATO_CENTRAL_CONEXAO.txt.
5) Clique em TESTAR E CONECTAR.
6) Faça o login com um usuário da Central ou cadastre um novo usuário.

A partir daí, usuários, empresas, documentos e exportações podem ser compartilhados através da Central.

CONDIÇÕES:
- As máquinas devem estar na mesma rede local.
- A porta 8765 deve estar acessível no servidor.
- Se o Windows Firewall solicitar permissão, permita em rede privada.
- O computador servidor precisa estar ligado para receber e distribuir novas alterações.
- O token do arquivo de conexão deve ser tratado como senha.

============================================================
7. DADOS PERSISTENTES
============================================================

No Windows:
%LOCALAPPDATA%\Exato\Central Fiscal\Dados

Arquivos importantes:
- central_fiscal.db → Arquivo Fiscal Local e dados fiscais;
- usuarios.db → usuários, credenciais protegidas, histórico e recuperação de senha;
- config.json → configurações locais e Central Compartilhada;
- EXATO_CENTRAL_CONEXAO.txt → conexão/token para clientes, quando este computador é servidor.

Não apague ou substitua essa pasta sem orientação.

============================================================
8. SE O COMPUTADOR CLIENTE NÃO CONSEGUIR CONECTAR
============================================================

Verifique:
- servidor ligado;
- Exato iniciado/configurado no servidor;
- computadores na mesma rede local;
- token correto;
- endereço do servidor correto;
- firewall permitindo a porta 8765 na rede privada.

Use MANUTENÇÃO → TESTAR/CONFIGURAR CENTRAL e SINCRONIZAR CENTRAL AGORA quando disponíveis.

10. SERVIDOR EXATO — INICIALIZAÇÃO AUTOMÁTICA NO WINDOWS
============================================================

Quando este computador estiver configurado como Servidor Central, a V143 registra o servidor para iniciar automaticamente no Windows para o usuário atual.

A entrada é criada automaticamente ao ativar o Servidor Central. Se a V143 for aberta em um computador que já estava configurado como servidor na V143, o registro também será atualizado.

Clientes não recebem essa inicialização automática.

============================================================
11. BACKUP AUTOMÁTICO
============================================================

O Servidor Central realiza backup automático diário.
O backup fica em:
%LOCALAPPDATA%\Exato\Central Fiscal\Dados\Backups

A rotina preserva os backups manuais e os backups criados antes de atualizações.
